# `examples/`

Small, complete programs, one per domain. Each folder has a `main.envo`, an `envo.envon`
manifest, and a README saying what it shows and from which milestone it runs.

| Example | Shows | Runs from |
|---|---|---|
| [`00-hello`](00-hello/README.md) | The one-line console program | M1 (lexes today) |
| `01-cli` | Argument parsing with `envo.cli` | M8 |
| `02-window` | A desktop window with `envo.ui` | M8 |
| `03-site` | A Lumen website | M9 |
| `04-3d` | A spinning cube | M11 |
| `05-ai` | Local inference | M12 |

Only examples that exist are linked. New examples are added when the feature they show
works, never before.
