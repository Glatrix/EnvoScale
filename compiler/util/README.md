# `compiler/util`

> **Status:** Started in **M3.1**.

Stage 2's support library, namespace `envoc.util`, on top of the Envo-S1 prelude:
string helpers (`Same`, `StartsWith`, `Decimal`, `Hash`) and `StrMap<V>`, a hash map from
strings to values. See [`docs/architecture/stage2.md`](../../docs/architecture/stage2.md).
