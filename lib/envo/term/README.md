# `envo.term`

> **Status:** Not started. Planned for **M8**. Tier when it lands: Experimental.

VT/ANSI engine, raw mode, input events, a diffing cell-buffer renderer, and the terminal renderer for `envo.ui` (TUI).

## Simple door

```envo
tui { Text("Hello, World!").Bold() }
```

## Full-control door

Direct cell-buffer access and escape-sequence level control.
