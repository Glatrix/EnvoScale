# `templates/`

> **Status:** Not started. Project templates arrive with **M5**; Lumen templates with **M9**.

| Folder | Used by | Contents |
|---|---|---|
| [`projects/`](projects/README.md) | `envo new <template> <name>` | `console`, `app`, `site`, `game`, `ai`, `lib`, `cli` |
| [`lumen/`](lumen/README.md) | `envo.web` / `envo.ui` | Landing, Docs, Blog, Dashboard, Portfolio, Store, Settings app, Chat app |

Templates are the **simple door** for whole projects. Every template is ordinary Envo
code built from public components, so any part can be overridden or replaced: there is
no template-only API.
