# Lumen templates

> **Status:** Landing and Docs are done (M9.4), as `envo.web.templates`
> (`lib/envo/web/templates/`); the EnvoScale website uses both.

Site and app templates built from Lumen components: Landing, Docs (used for EnvoScale's own
docs site), Blog, Dashboard, Portfolio, Store, Settings app, Chat app. Every template can
be overridden component by component. The ones that exist are library code, so a program
calls them; this folder will hold the starter projects `envo new` copies.
