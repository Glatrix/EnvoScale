# Lumen design language

> **Status:** Not started. Planned for **M8**.

The specification of Lumen: colour roles (light/dark/high-contrast, wide gamut), type scale on system fonts, a 4-pt spacing scale, continuous corners, translucent materials, spring motion that respects reduced-motion settings, and WCAG 2.2 AA accessibility by default. Tokens are written in EON.
